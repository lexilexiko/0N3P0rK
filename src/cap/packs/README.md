# Пакеты настроек радио

Пак (PACK) — это именованный набор настроек радио: он выбирает методику
захвата и задаёт её параметры. Пак описывает **с какими настройками** работать,
а методика — **какую логику выполнять**. Это независимые реестры: один пак
может использовать любую зарегистрированную методику.

Чтобы добавить пак, создай `pack_имя.cpp` в этой папке. Остальные файлы
регистрации и меню вручную менять не нужно.

## Минимальный шаблон

```cpp
#include "pack_ctx.h"

namespace Cap {
namespace Packs {

// Имя файла: pack_example.cpp
// TAG уникален между всеми pack_*.cpp.
// NAME показывается в RADIO -> PACK.
// METHOD_NAME — точное имя методики; nullptr оставляет выбранную методику.
static const Preset kExamplePreset{
    /* bidirKick     */ false,
    /* eapolTx       */ false,
    /* pmkidProbe    */ false,
    /* csaHerd       */ false,
    /* authFlood     */ false,
    /* kickBurst     */ 2,
    /* pauseMs       */ 1200,
    /* lockMs        */ 8000,
    /* hopMs         */ 300,
    /* jitterMs      */ 0,
    /* cooldownSec   */ 0,
    /* scoreThr      */ 0,
    /* hsDepth       */ 0,
    /* dataAct       */ 0,
    /* strictLock    */ true,
    /* depthHoldSec  */ 0,
    /* txPowerDb     */ 20,
    /* burstPattern  */ 1,
};

CAP_PACK_REGISTER(example, "EXAMPLE", "ALL", kExamplePreset)

} // namespace Packs
} // namespace Cap
```

`Preset` принимает значения в указанном порядке. Передавай в макрос уже
созданную переменную `Preset`, как в примере, а не фигурный список значений
непосредственно внутри `CAP_PACK_REGISTER`.

## Поля пресета

| Поле | Назначение |
|---|---|
| `bidirKick` | Включить используемое методикой двустороннее воздействие |
| `eapolTx` | Разрешить методике дополнительные EAPOL-действия |
| `pmkidProbe` | Разрешить зарегистрированный probe, если у методики он есть |
| `csaHerd` | Включить CSA-функцию для методик, которые её поддерживают |
| `authFlood` | Включить auth-flood для методик, которые его поддерживают |
| `kickBurst` | Число повторов, используемое методикой |
| `pauseMs` | Пауза после обнаружения EAPOL |
| `lockMs` | Время блокировки на канале после EAPOL |
| `hopMs` | Основной интервал переключения каналов |
| `jitterMs` | Дополнительная задержка между кадрами для поддерживающих её методик |
| `cooldownSec` | Пауза перед повторным выбором цели в FOCUS |
| `scoreThr` | Нижний порог выбора цели в FOCUS |
| `hsDepth` | Глубина handshake: `0` — M1–M2, `1` — M3, `2` — полный M1–M4 |
| `dataAct` | Использовать активность по data-кадрам в FOCUS |
| `strictLock` | В FOCUS не переключаться с заблокированной цели |
| `depthHoldSec` | Дополнительное удержание цели при `HS DEPTH` выше M1–M2 |
| `txPowerDb` | Мощность передачи, дБм |
| `burstPattern` | Форма пакета передачи: `0` — STRAIGHT, `1` — RANDOM, `2` — CLUSTER, `3` — PULSE |

**HS DEPTH остаётся пользовательской настройкой.** В имеющихся пакетах
пресеты выбирают `0` (M1–M2); пакет не заставляет ждать M3/M4. Если нужно
собирать глубже, выбери `HS DEPTH` вручную в RADIO. `depthHoldSec` помогает
удерживать цель только при выбранной глубине выше M1–M2.

`MIN DWELL` задаётся отдельно в RADIO и в `Preset` не входит. `OFF` отключает
дополнительное ограничение; иначе фактический интервал переключения каналов
не будет меньше `MIN DWELL` и `HOP MS`.

## Регистрация и правила

1. Помести файл в `src/cap/packs/` и подключи `pack_ctx.h`.
2. Зарегистрируй пак одной строкой в `namespace Cap::Packs`:
   `CAP_PACK_REGISTER(TAG, "NAME", METHOD_NAME, PRESET)`.
3. `TAG` — уникальный идентификатор C++; обычно совпадает с именем файла без
   `pack_` и `.cpp`.
4. `NAME` — короткое уникальное имя для меню PACK и нижней строки состояния.
5. `METHOD_NAME` — точное имя методики из `CAP_METHOD_REGISTER`; `nullptr`
   сохраняет выбранную методику, а не переключает её на `AUTO`.
6. Сохраняй настройки в `Preset`, расположенном перед строкой регистрации.

Не используй повторяющиеся `TAG` или `NAME`: одинаковые имена пакетов
неоднозначны в меню.

## Что происходит при выборе

- В **RADIO → PACK** доступны встроенные `STOCK`, зарегистрированные пакеты и
  `CUSTOM`.
- Выбор пакета применяет его `Preset`. Методика переключается только если
  пакет указал `METHOD_NAME`; при `nullptr` остаётся текущая. У `STOCK`
  методика `AUTO`; `CUSTOM` сохраняет текущие ручные настройки.
- Ручное изменение большинства параметров переводит выбранный пакет в
  `CUSTOM`, чтобы дальнейший выбор пакета не выдавал набор изменённых вручную
  параметров за исходный пресет.
- Состав меню формируется из реестра пакетов; порядок зарегистрированных
  пакетов определяется порядком их регистрации при сборке.
- Новая методика и новый пак регистрируются отдельно. Чтобы пакет выбрал
  новую методику, передай её точное имя в `METHOD_NAME`.

## Пакеты в проекте

| Имя в меню | Методика | Назначение |
|---|---|---|
| `SOFT` | `ALL` | Пассивный захват. Пакет выключает kick, EAPOL TX, PMKID probe, CSA и AUTH FLOOD; сниффер продолжает слушать и сохранять захваченные данные |
| `NORMAL` | `CLIENTS` | Сбалансированный пресет для методики CLIENTS |
| `LOUD` | `CLIENTS` | Более интенсивный пресет CLIENTS с дополнительными возможностями |
| `FOCUS` | `FOCUS` | Выбор одной цели по оценке и параметры фокусированного захвата |
| `QUIET` | текущая | Выключает `BIDIR` и `AUTH FLOOD`, включает PMKID. Пакет не меняет методику: чтобы использовать probe без deauth, выбери `FOCUS`; глобальный диспетчер передачи должен быть включён |
| `EVIL` | `eViL` | Пресет для адаптивной методики eViL |
| `MAX` | `FOCUS` | Интенсивный пресет для FOCUS |

Также доступны встроенные слоты `STOCK` и `CUSTOM`; они не регистрируются
файлами в этой папке.
