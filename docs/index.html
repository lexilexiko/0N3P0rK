What is 0N3P0rK?

Firmware for M5Stack Cardputer / Cardputer ADV: a living pig companion plus Wi‑Fi lab tools (handshake capture, spectrum, PigPass, loot browser).

Requirements

  • USB-C + Chrome / Edge / Opera (Web Serial)
  • microSD for captures, talk lines, and the file manager
